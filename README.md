# JetBlue Studio

Sitio web de JetBlue Studio (BRANDZMKT) — estudio creativo de branding, diseño digital, video, automatización con IA y marketing, con un hero 3D inmersivo y animaciones de scroll.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Three.js / React Three Fiber (escena 3D del hero)
- Motion (Framer Motion) para transiciones y micro-interacciones
- GSAP + ScrollTrigger para el resaltado de servicios en scroll

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```
